# StudioZIO Probe 0.18.0

StudioZIO Probe measures supported stereo AUv2 effects on macOS. Measurements are not sound-quality scores, certification, or product acceptance decisions.

## Distribution changes

- Bundles Python 3.14.9; no separate Python, Homebrew, or Xcode installation is required.
- Universal arm64 and x86_64 binaries target macOS 13 or later.
- Stores runs, captures, and imports in `~/Library/Application Support/StudioZIO Probe/`.
- Removes generated bytecode caches and local build paths from the packaged calibration receipt.
- Preserves the existing measurement algorithms. The calibration receipt uses a signature-independent native implementation hash; it remains valid after signing and detects a tested executable-code mutation.

## Verification scope

Runtime testing was performed on Apple silicon with macOS 27 on the build Mac. The original candidate passed 17 installation and engine checks, including six self-tests, fixture state capture, a default run, report export/import, and unchanged installed bundle contents. The sanitized app passed all six packaged self-tests again and retained a valid calibration binding.

Intel execution, macOS 13–26 execution, a clean Mac installation, and full visual UI interactions have not been tested. The macOS 13 minimum is a build target, not a claim of runtime testing across every version. The original launch check covered startup, data-folder creation, running time, and a clean quit. Third-party plugin compatibility is not universal.

The final app and DMG are Developer ID signed, accepted by Apple's notarization service, and stapled. Strict signature verification, Gatekeeper assessment, and stapler validation pass.

## Install and verify

Download `StudioZIO-Probe-0.18.0.dmg` and `SHA256SUMS.txt` from this release. In the download directory, run:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Open the DMG, drag StudioZIO Probe to Applications, and open it there. macOS may show its normal first-open confirmation. See `INSTALL.md` for use, storage, and removal instructions.

The repository contains distribution documentation. The private source archive and internal signing, notarization, and test logs are not release assets. Bundled third-party notices remain inside the app.
